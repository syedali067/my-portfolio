About

A bit about how I got here.

I'm a Computer Science graduate (BSCS, COMSATS University Islamabad, Abbottabad Campus) now working as an independent freelance MERN Stack Developer based in Lahore, Pakistan. Before going freelance, I spent about a year and a half as a Junior MERN Stack Developer at Codedile Solutions, building and maintaining responsive React.js interfaces, consuming REST APIs, and implementing JWT-based authentication — the practical, production side of full-stack development rather than just tutorials.

My core stack is React.js, Next.js, Node.js, Express.js and MongoDB, with Tailwind CSS for UI and Redux Toolkit or Zustand for state management depending on the project. Working independently, I've designed and built full-stack apps end to end — including VideoTube and MegaBlog — covering both frontend and backend, and containerized a patient portal frontend (Kinsyn) with Docker.

I'm currently deepening my backend skills with Node.js, Express.js, MongoDB and JWT authentication, and self-studying DevOps fundamentals — Docker, CI/CD pipelines, and Linux/Nginx basics — to support end-to-end delivery of full-stack projects.
